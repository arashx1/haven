Supabase Backend & PostgreSQL Cloud Architecture

Table Name Columns & Keys Security / RLS Rule
profiles id, email, full_name, role, condition Users can read and update only their own profile.
reminders id, user_id, title, time, pill_color, completed Caregivers & patients filter reminders by authenticated user_id.
memories id, user_id, title, date, story, image_url Private family photos protected with row-level ownership constraints.
people id, user_id, name, relationship, phone, avatar_url Restricted to caregiver/patient family circle.
Resilient Mock Layer src/lib/supabaseClient.ts:L23-125 Offline mock client ensures 0 crashes if reviewers run without internet or credentials.

Frontend, Internationalization & Accessibility

  • React 18 + Vite 5: Ultra-fast build (built in 5.95s on Vercel CI/CD) and responsive layout.
  • Multilingual i18n (7 Languages): English, Spanish, French, Chinese, Hindi, Bengali, Assamese.
  • Accessibility (A11y): Dynamic tactile font scaling (A− / A+) and WCAG AAA color contrast.
  • Web Speech & Web Audio APIs: Local speech synthesizer reads stories aloud with 0 third-party API latency.
  • Bespoke Brand Favicon Suite: Scalable vector SVG, 32×32 PNG, ICO, and Apple Touch Icon.
